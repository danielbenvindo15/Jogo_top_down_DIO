# Jogo Top Down DIO

### Como foi criado:
Esse jogo foi criado durante o bootcamp de Godot da DIO, para a criação desse jogo, foram utilizados como assets os pacotes [Tiny Swords](https://pixelfrog-assets.itch.io/tiny-swords) (por Pixel Frog) e o [Particle Pack](https://www.kenney.nl/assets/particle-pack) (por Kenney). Caso esteja interessado em apenas jogar o jogo sem a necessidade de baixar arquivos do código fonte: [CLIQUE AQUI PARA JOGAR!](https://daniel-benvindo15.itch.io/jogo-top-down)

### Mecânicas adicionadas:
- Ataque especial
- Invocação de Inimigos
- Contagem de tempo
- Sistema de game over
- Drops aleatórios

### Conteúdos para talvez adicionar em futuras atualizações:
- Tela de título
- Sistema de Ondas de dificuldade
- Músicas e Efeitos Sonoros
